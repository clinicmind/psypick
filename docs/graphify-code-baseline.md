# PsyPick 程式依賴基線（Graphify 執行前）

日期：2026-10-11。來源：`main` 分支的 `site/index.html` 和 `site/app.js` 原始碼。這是**靜態原始碼閱讀**，不是 Graphify 實測輸出，也不是執行期測試。

## 已確認結構

- `site/index.html` 載入 `style.css` 和 `app.js`，主要容器為 `#app`。
- `site/app.js` 約 946 行，包含路由、內容載入、收藏、搜尋、親子、會議、人物動向、支援按鈕等功能。
- `site/data/` 為內容資料區；不得在本試點修改。
- `README.md` 指出 main 分支的推送會透過 Cloudflare Workers Builds 觸發部署，因此試點只在獨立分支及 Draft PR 中進行。
